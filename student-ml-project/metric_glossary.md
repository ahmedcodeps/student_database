# Metrics Glossary

## Supervised Learning
Learning from examples that already have known answers.
This project uses supervised learning to predict student outcomes.

## Unsupervised Learning
Finding patterns in data without known answers.
For example, grouping students with similar study habits.

## Features
The information used to make predictions.
Examples: attendance, study hours, and previous scores.

## Label
The answer the model is trying to predict.
In this project:
- 0 = Pass
- 1 = Needs Support

## Training Data
The data used to teach the model.

## Test Data
Separate data used to check the model's performance.

## Accuracy
The percentage of predictions that were correct.

## Precision
How many predicted support cases were actually labeled
as needing support.

## Recall
How many actual support cases the model correctly identified.

## F1 Score
A score that combines precision and recall.

## Confusion Matrix
A table showing correct and incorrect predictions.

## Baseline
A simple model used as a starting point for comparison.
This project uses a model that always predicts the most
common class.

## Overfitting
When a model learns the training data too closely and
performs worse on new data.

A large difference between training and test accuracy
can be a warning sign.

## Bias
Problems that can happen when training data is incomplete,
unrepresentative, or contains unfair patterns.

## Model Limitations
Models can make mistakes. Their predictions may not work
well on different datasets or real-world situations.
