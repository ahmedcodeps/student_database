# Student Performance Analysis

## Purpose

This project analyzes student performance using Python,
pandas, and matplotlib.

It explores exam scores, attendance, study hours,
correlations, and differences between a sample and
the full dataset.

## Dataset

Student Performance Factors:
https://www.kaggle.com/datasets/lainguyn123/student-performance-factors

Download the CSV and rename it to
StudentPerformanceFactors.csv.

## Setup

Install Python 3 and open the folder in VS Code.

Create a virtual environment:

    python3 -m venv .venv
    source .venv/bin/activate

Install packages:

    python -m pip install -r requirements.txt

Open student_analysis.ipynb and run all cells.

## Results

The notebook generates:

- Statistical summary
- Correlation analysis
- Five charts
- Random sample comparison
- Spreadsheet-readable CSV files
- Five written insights

The outputs are saved in the outputs folder.

## Correlation and Causation

Correlation describes how two variables change together.
It does not prove that one variable causes another.
Other factors may influence student results.

## Limitations

The findings describe the selected dataset only.
The data may not represent every student or school.
The analysis should not be used to make important
decisions about individual students.
