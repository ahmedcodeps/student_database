# Q&A Assistant Testing (sample responses)

## Test 1
**Question:** What is photosynthesis?

**Answer:** Photosynthesis is the process plants use to make their own food. They use sunlight, water, and carbon dioxide to produce glucose and release oxygen.

## Test 2
**Question:** What is the difference between supervised and unsupervised learning?

**Answer:** Supervised learning uses labeled data to learn how to make predictions. Unsupervised learning uses data without labels to find patterns or groups.

## Test 3
**Question:** What is a Python variable?

**Answer:** A variable is a name used to store information in a program. For example, `age = 15` stores the number 15 in a variable called age.

## Test 4
**Question:** Why is exercise important?

**Answer:** Exercise helps keep the body healthy. It can strengthen muscles and bones, improve heart health, and support mental well-being.

## Test 5
**Question:** Explain how solar panels work.

**Answer:** Solar panels use photovoltaic cells to convert sunlight into electrical energy. This electricity can then be used to power homes and other devices.
